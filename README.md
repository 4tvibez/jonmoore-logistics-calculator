# Jonmoore International - Interactive Freight Cost Calculator (Concept)

A lightweight, high-performance web tool built to modernize logistics client onboarding. This project acts as a direct concept proof showcasing how an automated, mobile-responsive interface can replace manual email/call quote requests for heavy haulage operations in Ghana.

## 🛠️ The Business Problem & Front-End Solution
Traditional logistics inquiries require back-and-forth communication regarding weight, transit distance, and cargo type. This project solves that friction by providing:
- **Instant Estimation Engine:** A vanilla JavaScript mathematical module calculating rates based on localized GHS transport profiles.
- **Dynamic Surcharge Logic:** Automated handling of weight variables over 10 tons using scalable conditional algorithms.
- **Mobile-First Layout:** Tailored with fluid CSS variables and responsive breakpoints optimized for field operators using mobile data networks.

## 💻 Tech Stack
- **Structure:** Semantic HTML5
- **Styling:** Custom CSS3 (utilizing modern CSS variables and flexbox/grid layout paradigms)
- **Logic:** Vanilla JavaScript (ES6+ architecture, safe DOM manipulation, and dynamic event binding)
